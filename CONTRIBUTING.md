# Contributing

Mailshift welcomes small, reviewable pull requests.

1. Fork and clone the repository.
2. Run `npm install`.
3. Create a focused branch.
4. Run `npm run check`.
5. Open a pull request explaining the user problem and security impact.

Playbook changes must link to official service documentation, include a
current `lastVerified` date, and avoid suggesting that users share credentials
with Mailshift. Do not add mailbox access, credential collection, analytics,
or automatic account login without first discussing the threat-model change.
